# MOGA Pocket Bridge

See [readme.md](./readme.md) for the project architecture, hardware/protocol notes, Android no-root limitations, and development setup.

This repository contains a Rust protocol parser, a mock transport, a Tauri Android plugin bridge for Classic discovery and user-confirmed RFCOMM pairing, and a configurable `InputMethodService` keyboard mapper. See the detailed setup and platform limitations in [readme.md](./readme.md).
